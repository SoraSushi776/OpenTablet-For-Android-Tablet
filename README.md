# Android HID 数位板

将 **Android 平板** 的触控 / 触控笔输入，通过 **USB HID Gadget** 输出为标准**绝对定位数位板**信号。主机插上后，一般由系统自带的数位板/手写笔栈识别使用，**不依赖 OpenTabletDriver 等第三方驱动**。

```
┌─────────────┐   MotionEvent   ┌──────────────────┐   /dev/hidg0   ┌──────────────┐
│ Android 平板 │ ──────────────► │ Kotlin UI + JNI  │ ─────────────► │ 主机系统      │
│ 触控 / 笔    │                 │ C++ 映射与写入    │   USB HID      │ 数位板输入栈  │
└─────────────┘                 └──────────────────┘                └──────────────┘
```

---

## 功能

- 触控笔 / 手指 → **0–32767** 绝对坐标 + **0–8191** 压感
- **悬停**：笔在空中移动时主机光标跟随（in-range + 压感 0）
- **落笔稳定**：tip 状态机 + 队列合并，避免光标闪烁
- **坐标映射**：16:9 / 16:10 / 4:3，缩放 %、偏移 %，设置页预览，可保存预设
- **压感曲线**：可拖拽编辑；落笔判定、下笔最低压感、曲线中点；预设「仅点击优化 / PS 绘画 / 默认」
- **快捷键 HID**（`/dev/hidg1`）：撤销/重做/画笔/橡皮等 + Ctrl/Shift/Alt

## 工作原理

### USB HID Gadget（需要 Root）

App 通过 **ConfigFS** 创建 USB HID 设备：

| 节点 | 用途 | 报文 |
|------|------|------|
| `/dev/hidg0` | 数位板（Digitizer / Pen） | 8 字节 |
| `/dev/hidg1` | 键盘 | 8 字节 |

挂载时会：停止 `adbd`、避免系统改回 ADB → 写入 Report Descriptor → 绑定 UDC → `chmod 666` 设备节点。退出时尽量恢复 ADB 与 SELinux。

### 数位板报文（8 字节）

| 字节 | 含义 |
|------|------|
| 0 | 状态：`bit0` tip/感应，`bit1` 侧键，`bit2` 橡皮 |
| 1–2 | X `uint16` LE，`0–32767` |
| 3–4 | Y `uint16` LE，`0–32767` |
| 5–6 | 压感 `uint16` LE，`0–8191` |
| 7 | 保留 |

- **悬停**：`bit0=1`，压感 `0`，坐标有效  
- **落笔**：`bit0=1`，压感 `>0`（经曲线与最低压感处理）  
- **抬笔**：`bit0=0`，压感 `0`  

主机端使用标准 **HID Digitizer** 报告描述符；Windows / macOS / Linux 通常可通过系统数位板或手写笔输入直接处理。

### 坐标映射

触控坐标为右侧触控 **View** 本地坐标：

1. 按比例求 View 内最大内接矩形  
2. × 缩放 %  
3. 按偏移 X/Y %（相对 View）平移  
4. 区域内归一化到 `0–32767`，区域外 clamp  

### 压感与点击

- **压感**：供绘图软件笔刷透明度/流量  
- **左键/落笔**：与主机如何绑定笔尖有关；在 App 内可通过「下笔最低压感」保证接触后至少输出一定压感，减轻「必须用力按」的问题  
- 曲线：`(0,0) → (midX,midY) → (1,1)`，再 floor 到最低压感、乘上限

## 环境需求

### Android 平板

| 项目 | 要求 |
|------|------|
| 系统 | Android 12L+（`minSdk 32`） |
| 权限 | **Root**（ConfigFS / HID Gadget / SELinux） |
| USB | 支持 USB Device/Gadget（存在 UDC） |
| 输入 | 推荐触控笔；手指可在数位板界面打开 |

### 主机（可选，视系统而定）

| 情况 | 说明 |
|------|------|
| **推荐** | 系统能识别 USB HID 数位板/手写笔（多数 Windows、部分 Linux 发行版） |
| 系统不识别时 | 可自行安装任意兼容标准 Digitizer HID 的驱动/输入中间件（**非必需**，本 App 不再附带第三方驱动配置导出） |
| 映射/压感 | 优先在 **本 App 设置页** 完成；主机侧区域映射视系统设置而定 |

> 说明：只要主机把设备当成「绝对定位数位板/笔」，即可使用。本工程**不绑定** OpenTabletDriver；若你所在环境系统无法处理该 HID 设备，再自行选择主机端方案即可。

### 构建（开发者）

| 项目 | 要求 |
|------|------|
| JDK | 17+ |
| Android SDK | `compileSdk 37`（`local.properties` → `sdk.dir`） |
| NDK / CMake | NDK，CMake **3.22.1** |

```bash
./gradlew :app:assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

## 使用步骤

1. 安装 APK，授予 Root  
2. 主页 → **挂载 HID 设备**（`/dev/hidg0` 已就绪）  
3. **设置** 中调整映射比例/缩放/偏移与压感曲线（可保存预设）  
4. USB 连接主机，确认主机识别到数位板/笔类设备  
5. 主页 → **启动数位板**，在右侧蓝框区域内书写  
6. 结束后 **退出数位板**；调试需要 ADB 时 **取消挂载并恢复 ADB**

## 常见问题

**Q: `/dev/hidg0` 不存在？**  
A: 需 Root 且内核支持 ConfigFS HID Gadget；先执行「挂载 HID 设备」。

**Q: 主机没有反应？**  
A: 在主机设备列表中查看是否出现 USB HID 数位板/手写笔。部分系统需在设置中启用数位板输入，或关闭与之冲突的其它平板驱动。

**Q: 落笔要很用力才有点击？**  
A: 设置 → 压感曲线 → 提高「下笔最低压感」，或点「仅点击优化」。

**Q: 悬停光标不动？**  
A: 确认 App 触控区有 hover 指示；部分主机对「悬停包」处理不同，可看系统数位板设置。

**Q: 挂载后无法 adb？**  
A: App 会停 adbd 以免 USB 被改回 ADB。用「取消挂载并恢复 ADB」，或手动 `setprop sys.usb.config adb` 并 `start adbd`。

## 安全与限制

- 需要 **Root**；挂载阶段可能临时关闭 SELinux Enforcing 与 adbd  
- 依赖设备内核已支持 USB HID Gadget  
- 仅在自用设备上使用
